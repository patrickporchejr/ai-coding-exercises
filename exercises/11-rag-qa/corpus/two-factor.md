# Two-factor authentication

Tidepool supports two-factor authentication (2FA) with authenticator apps that generate time-based codes (TOTP), such as 1Password, Authy, or Google Authenticator.

SMS codes were removed as a 2FA option in **August 2025** for security reasons. Accounts that used SMS were moved to email-based verification until they set up an authenticator app.

When you turn on 2FA, you get **10 one-time recovery codes**. Store them somewhere safe; each code works once.

Workspace admins can require 2FA for all members under **Settings > Security**.
